# ADR-001 — Python como Linguagem de Programação 

**Data:** 26/08/2026  

**Estado:** Proposto 

**Decisores:** Rafael Flor

---

## Contexto

Para o desenvolvimento do projeto existe a necessidade de optar por uma linguagem de programação adequada. A escolha pode ter impacto em aspetos como a complexidade da implementação, risco no desenvolvimento e a disponibilidade de bibliotecas e ferramentas.

---

## Decisão

Foi decidido utilizar Python como linguagem de programação principal no desenvolvimento da aplicação Musical Theory Trainer. 

---

## Alternativas consideradas


| Alternativa | Razão de rejeição |
|------------|------------------|
| C++ | Para a aplicação em causa, não se considera que o possível aumento de eficiência em tempo de execução, que o C++ poderia fornecer, seja crucial. Adicionalmente, o uso de C++ poderá resultar numa maior complexidade de implementação, assim como na elevação do risco durante o desenvolvimento, devido à necessidade de lidar com elementos de nível mais baixo.  |
|Java | Apesar de também ser uma alternativa viável em termos de funcionalidade e bibliotecas disponíveis, a sintaxe mais verbosa típica do Java e a familiaridade com Python foram os principais fatores de decisão. Considera-se que a decisão pelo Python possa contribuir para uma menor complexidade de implementação e diminuição de risco associado ao desenvolvimento.


---

## Consequências

**Positivas:**
- Disponibilidade de várias bibliotecas úteis no desenvolvimento da aplicação em causa
- Potencial diminuição da complexidade da implementação
- Potencial diminuição do risco durante o desenvolvimento
- Maior familiaridade com a linguagem 

**Negativas / trade-offs:**
- Potencial diminuição da eficiência em tempo de execução
